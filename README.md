# 世界史単語年表

世界史の出来事・人物・国家・文化を同じ時間軸で探索できるインタラクティブ年表です。

## 使い方

- 下の再生バー（または「縦」モードでは右側のバー）で年代を移動します。
- 右上のボタンで表示を切り替えられます。
  - **ランダム**：初期表示
  - **関連性**：関連語が親の語のすぐ隣に集まり、単語にマウスを近づけるとその単語の関係が直線で表示されます
  - **地理**：ヨーロッパ・アジア・アフリカ・オセアニア・アメリカの目安範囲に配置します
  - **戦争**：進行中の主要戦争の参加国を陣営ごとに色分けし、味方同士を直線でつなぎます
  - **文化史**：美術・宗教・哲学・科学・書籍などだけを表示します
- 単語をクリックすると、説明・関連語・画像が表示されます。

## 出典

- 各語の説明には出典リンクがあります（Wikidata、Britannica、OpenStax などを含む）。
- 画像は Wikimedia Commons のファイルを表示しています。各画像の下のリンクからファイルページ（作者・ライセンス）を確認できます。

## ファイル

`index.html` 1ファイルで動作します（画像の表示にはインターネット接続が必要です）。
